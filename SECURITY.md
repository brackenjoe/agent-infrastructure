# Security

This repo describes security boundaries: which machine can reach which, what
an agent may touch, and how a web server talks to a TAK Server. If you find
a way around one of them, or something here that weakens a setup copied
from it, report it privately rather than in an issue.

**Report** through GitHub's private vulnerability reporting: the
**Security** tab, then **Report a vulnerability**. Say which file and
section, what an attacker could do, and what you would change.

Reports are read by one person, so expect a reply in days rather than
hours. A confirmed problem is fixed in the guide, and the fix says what
changed.

In scope: the guide's configuration, scripts and procedures. Out of scope:
Claude Code, Tailscale, Cloudflare, TAK Server and other vendors' products;
report those to the vendor.
